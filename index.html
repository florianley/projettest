01 — Système

Un site, trois fichiers.

La v2 garde la promesse de la v1 : du HTML, du CSS et un peu de JavaScript, servis tels quels. Aucun gestionnaire de paquets, aucun pipeline.

Zéro build

Ouvrez index.html : c'est déjà en production. Pas d'étape de compilation, pas de sortie de build à maintenir.

Zéro dépendance

Aucun CDN, aucune police distante, aucun tracker. Le réseau n'est sollicité que pour les fichiers du site.

100 % statique

Compatible GitHub Pages, Netlify, Cloudflare Pages ou n'importe quel serveur de fichiers, sans configuration.

02 — Terminal

Une démo qui se tape toute seule.

Le seul JavaScript ajouté en v2 pilote le thème, les révélations au scroll et cette petite session de terminal. Rien de plus.

  • Thème Sunset / Matrix mémorisé en local
  • Animations désactivées avec prefers-reduced-motion
  • Navigation clavier et lien d'évitement

Démonstration : la commande npm run hello affiche HELLO WORLD, prête en 0,00 s, sans build ni dépendance.

hello@synthwave: ~
